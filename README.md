🧛 TOC… TOC… SURVIVE 🧛
Documentação do Jogo
🎮 Sobre o Jogo
TOC… TOC… SURVIVE é um jogo de suspense e
sobrevivência.
O jogador deve analisar visitantes misteriosos que
batem na porta e decidir se eles são humanos ou
vampiros.
Entre os personagens do jogo existem:
● 6 Humanos
● 3 Vampiros
Cada escolha feita pelo jogador pode alterar o resultado
da partida.
🏠 Menu Inicial
Ao iniciar o jogo, aparecem as seguintes opções:
● Logo do jogo
● Botão “Iniciar”
● Botão “Sair”
Funções
▶ Iniciar
Começa uma nova partida.
❌ Sair
Fecha o jogo.
📖 Manual do Jogo
Antes de começar, o jogador deve ler o manual do jogo.
O manual explica:
● Como identificar vampiros
● O que deve ser analisado nos visitantes
👥 Personagens
O jogo possui um total de 9 personagens:
● 6 Humanos
● 3 Vampiros
Cada personagem possui informações diferentes para
análise.
🔎 Sistema de Análise
Quando alguém bate na porta, o jogador deve analisar
as informações do visitante.
📄 Documento
O documento apresenta:
● Nome
● Idade
● Data de nascimento
O jogador deve verificar se as informações parecem
corretas.
🌡 Temperatura
O jogador pode verificar a temperatura corporal do
visitante.
● Humanos possuem temperatura normal.
● Vampiros podem apresentar temperatura baixa.
💬 Falas e Informações
Durante a interação, o visitante pode apresentar
informações diferentes.
O jogador deve observar possíveis respostas suspeitas.
⚖ Decisão do Jogador
Após analisar todas as informações, o jogador precisa
tomar uma decisão.
🚪 Deixar Entrar
Escolha utilizada quando o jogador acredita que o
visitante é humano.
❌ Expulsar
Escolha utilizada quando o jogador acredita que o
visitante é um vampiro.
☠ Consequências
Se expulsar um humano:
● O jogador recebe penalidade.
Se deixar um vampiro entrar:
● O jogador perde a partida.
📌 Fluxo do Jogo
1. Abrir o jogo
2. Ler o manual
3. Esperar alguém bater na porta
4. Analisar:
○ Documento
○ Temperatura
○ Informações apresentadas
5. Decidir se é humano ou vampiro
6. Expulsar ou deixar entrar
